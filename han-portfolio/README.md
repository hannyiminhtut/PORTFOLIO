# Han Nyi Min Htut — Portfolio

React + TypeScript + Vite, with Lucide icons and custom responsive CSS.

## Run locally

From this folder:

```powershell
npm install
npm run dev
```

Open the local URL printed in the terminal. Edit `src/main.tsx` for content and components, and `src/styles.css` for design. Images live in `public/assets`.

## Production build

```powershell
npm run build
npm run preview
```

`dist/` is generated build output. Do not edit it directly; builds replace it.
